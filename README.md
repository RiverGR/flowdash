## 0. 프로젝트 개요 (간단 요약)

본 프로젝트는 공통 요구사항을 기반으로 한  
칸반 형태의 태스크 관리 대시보드(Todo-List) 구현 과제입니다.

CRUD, 기간 필터, 통계, 테마 및 UX 요소를 포함하며  
팀 단위 협업을 통해 설계 및 구현을 진행하였습니다.

---

## 1. 팀 구성 및 역할 분담 (Team & Roles)

| 이름   | 역할                            | 주요 담당                                      | 비고                           |
| ------ | ------------------------------- | ---------------------------------------------- | ------------------------------ |
| 이가람 | App Initialization & State Flow | 앱 구조, 상태 흐름, 부팅 중복 방지 관리        | UI 구조 및 디자인 설계 및 협업 |
| 최은주 | Feature UI                      | 할 일 추가, 필터, 대시보드 UI 및 기능 구현     | 디자인 협업                    |
| 한찬우 | UX / Theme                      | 닉네임, 인삿말, 테마 로직 기능 구현 및 UI 보완 | CSS 디테일 수정                |

- JavaScript는 전체적인 디자인을 설계한 후, 각각의 섹션 별로 기능을 구현하였습니다.
- css는 팀장()
- 공통 스펙 변경은 팀 합의 후 진행

---

## 2. 수행 절차 및 방법 (Process & Strategy)

### 2-1. 진행 순서

1. 필수 요구사항 분석, 선택 기능도 가능하면 구현
2. Todo 데이터 구조와 LocalStorage Key 요구사항에 맞게 설정
3. 앱 구조 설계와 디자인 설계
4. 핵심 기능(필터 / CRUD / 대시보드 / 통계) 구현
5. 핵심 UX 기능(닉네임 / 인삿말 / 테마전환)도 구현
6. UI, UX 개선, 버그 수정

### 2-2. 협업

- 기능 단위(닉네임 / 인삿말 / 통계 그 외 등등)로 JS 파일을 분리하여 작업
- 공통 상태와 후에 선택적으로 추가한 기능은 'app.js'파일에서 관리하도록 협의
- UI 모듈은 서로 직접 의존하지 않을 수 있도록 설계
- 변경 사항(pull / push)들은 즉시 팀원 간 서로 공유 후 반영
